# EFX

EFX هو إطار مستقل لتطوير قواعد البيانات في .NET.

الفكرة هي تجربة طريقة مختلفة للتعامل مع قواعد البيانات، يكون فيها C# Model هو نقطة البداية، من دون الاعتماد على Entity Framework Core.

النسخة الأولى تركز على اكتشاف الـ Models، فحص مخطط SQLite، مقارنة الـ Models بقاعدة البيانات، إنشاء خطة تغييرات، توليد SQL، ثم تطبيق التغييرات بعد المراجعة.

SQLite هو أول Provider نستخدمه لبناء النواة وتجربة التصميم.

المشروع في مرحلة مبكرة جدًا، ولا يدعي أنه بديل لـ EF Core أو أنه جاهز للإنتاج.

## هيكل المشروع

- `src/EFX.Core` - النواة
- `src/EFX.Sqlite` - دعم SQLite
- `src/EFX.Cli` - أوامر الطرفية
- `samples/EFX.Sample` - مشروع تجريبي
- `tests/EFX.Tests` - الاختبارات
- `docs` - التوثيق وخطة التطوير
