# EFX

**EFX هو إطار عمل مستقل لتطوير قواعد البيانات في بيئة .NET، أُنشئ بطموح أن يصبح بديلاً أكثر قوة وتطوراً من Entity Framework Core.**

يعتمد EFX على منهجية Model-First، بحيث يكون نموذج C# هو نقطة البداية في عملية تطوير قواعد البيانات وإدارتها.

رؤية المشروع هي تقديم طريقة أبسط وأكثر وضوحاً وتحكماً في التعامل مع قواعد البيانات، دون الاعتماد على Entity Framework Core.

الهدف طويل المدى ليس مجرد إنشاء ORM آخر، بل إعادة التفكير في تجربة تطوير قواعد البيانات اليومية داخل بيئة .NET.

## الرؤية

يهدف EFX إلى تقديم منظومة مستقلة ومتكاملة لتطوير قواعد البيانات، تشمل:

- تعريف النماذج واكتشافها.
- إدارة بنية قواعد البيانات.
- مقارنة النماذج مع بنية قاعدة البيانات الفعلية.
- إنشاء خطط ذكية للتغييرات والترحيلات.
- توليد أوامر SQL وتنفيذها.
- الاستعلام عن البيانات وإدارة عمليات قواعد البيانات.
- دعم عدة أنواع من قواعد البيانات.

طموحنا هو جعل تطوير قواعد البيانات أكثر سهولة ووضوحاً وموثوقية وقوة.

## المرحلة الأولية

تركز مرحلة التطوير الأولى على:

- اكتشاف نماذج C#.
- فحص بنية SQLite.
- مقارنة بنية قاعدة البيانات.
- إنشاء خطط واضحة ومقروءة للتغييرات.
- توليد أوامر SQL.
- توفير آلية واضحة للتحقق من التغييرات قبل تطبيقها على قاعدة البيانات.

تُستخدم SQLite كأول مزود لقواعد البيانات بهدف تأسيس المعمارية الأساسية والتحقق منها.

## هيكل المشروع

- `src/EFX.Core` - البيانات الوصفية للنماذج والتخطيط الأساسي.
- `src/EFX.Sqlite` - مزود SQLite.
- `src/EFX.Cli` - واجهة سطر الأوامر.
- `samples/EFX.Sample` - تطبيق تجريبي.
- `tests/EFX.Tests` - الاختبارات.
- `docs` - التوثيق والمعمارية وخطة التطوير.

## الأوامر قيد الاستكشاف

```bash
efx db plan
efx db script
efx db apply
```

## حالة التطوير

EFX حالياً في مرحلة التأسيس والتطوير الأولي كمشروع مفتوح المصدر.

تركز المرحلة الحالية على بناء المعمارية الأساسية والتحقق من آلية العمل المعتمدة على Model-First.

الرؤية المستقبلية هي تطوير EFX ليصبح إطار عمل متكاملاً ومستقلاً لتطوير قواعد البيانات في .NET، بطموح يتجاوز قدرات وتجربة استخدام الحلول الحالية، بما فيها Entity Framework Core.

الميزات والأوامر المذكورة ضمن خطة التطوير أو قيد الاستكشاف ليست بالضرورة منفذة حالياً.
